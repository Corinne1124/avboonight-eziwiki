# 主世界大陆

[[god-mw|大陆之神]]栖息于此。

曾经富饶的世界，如今只剩下十五片大陆：

极北的北大陆：生冰之神栖息于此，生命种类最丰富，气候最寒冷，地形多为冰川冻原

极东的东大陆：山木之神栖息于此，植物与矿石最丰富，地形多为丛林与山峰沟谷

极南的南大陆：雷日之神栖息于此，各类资源最为稀缺，生命少而强大，气候最炎旱，地形多为沙漠与热带草原

极西的西大陆：水风之神栖息于此，资源适宜，气候多风多雨，适合生命居住繁衍，地形多为平原

正中的央大陆：始祖之人居住在此，科技改造环境，技术最发达，拥有大量人才，是人类的中心
