# 图片目录

此文件夹存放文档中使用的图片。

## 结构

- `docs/` - 文档图片（示意图、说明图等）
- `screenshots/` - 截图
- `icons/` - 图标和小图片

## 用法

在 Markdown 文件中这样引用图片：

```markdown
![描述](/images/docs/example.png)
![截图](/images/screenshots/demo.png)
![图标](/images/icons/logo.svg)
```

## 图片优化建议

- PNG：截图、需要透明背景的图片
- JPG：照片、复杂图片
- SVG：图标、Logo、矢量图形
- WebP：面向现代浏览器的优化格式
