# 残炬执锋
人类顶尖小队【残炬执锋】
 
定位：小规模精英作战单元，编制固定3‑5人，现世人类阵营天花板战力，隶属于烬火守序，但拥有独立行动权限。整体综合战力峰值T0.5中位，无单人抵达T0.5，力量依靠多人联动叠加达成层级；全员仍是纯粹人类，没有忌夜本源，力量全部来自禁忌仪式、改造遗械、生死契约。
不能对抗T0本体，仅可周旋T0投影/分身
 
组织根源
 
烬火守序余烬议院筛选出的绝境特化小队。
不负责大规模防线驻守，专门处理常规部队无法应对的高危突发事件：高位畸变突围、恶魔麾下三巨头局部突袭、裂隙突发性膨胀、被敌方领域掳走人员的救援行动。
不做大兵团正面会战，主打突袭、破域、救援、斩首局部目标。
人数严格锁死3‑5人，不会扩编。每有成员阵亡，才会经过严苛筛选补位，宁缺毋滥。
小队拥有战术自主权，烬火守序只下达任务目标，执行方案全部由小队自行决断；但受议院约束，严禁私自与忌夜存在签订交易契约。
 
核心机制：残炬同契
 
小队的力量根基，一份多人绑定的殉道类契约。
并非把人变成鬼怪，而是共享生命余量、感官情报、代价分摊。
 
- 战斗中所有成员意识互通，同步解析敌方权能流转、领域运转破绽。
- 发动高阶能力的代价，可以由小队成员共同分摊，避免单个人瞬间耗尽生命。
- 短板：契约是绑定的，一旦其中一人精神崩溃、陨落，其余所有人都会承受反噬损伤。成员不能相隔无限遥远，超出有效距离，同契直接失效，战力断崖下跌。
 
层级说明：单人实力处于T1‑T1极限，依靠残炬同契联动叠加，小队合力才能摸到T0.5中位。拆开之后，小队直接失去顶尖作战能力。
 
作战手段（无天生权能，人类体系）
 
1. 破械套件（改造战争遗械）
 
整套武器经过殉仪厅仪式锻造，取材旧时代战争遗物，灌注历代殉道者残留意志。
没有毁灭一切的威力，核心功能：撕裂、扰动敌方私域领域的边界。
专门针对古德里安【铁围闪决】、邓尼茨【冥渊囚海】、里希特霍芬【陨空焦域】这类强制拉入领域。
 
- 无法彻底销毁T0.5专属私域，但可以轰击领域壁垒，制造短暂缺口，救出被拖拽拘禁的目标。
- 短时间干扰领域的拖拽牵引效果，争取撤退窗口。
- 对T0投影衍生领域仅能造成微弱扰动。
 
2. 共燃仪轨【小队专属联合领域：残炬隔障】
 
必须至少3人同契联动才可以展开。
属于防御‑干涉型联合领域，不具备强制拖拽拉入敌人的能力。
效果：
 
1. 在小队周边构建人类意志凝聚的隔绝边界，抵抗T0.5领域的强制拉入效果，大幅降低被掳入私域的概率。
2. 领域内部，残炬同契的情报共享、代价分摊效率提升。
3. 可以向外打出震荡波，冲击敌方领域外壁，制造短暂裂隙。
4. 限制：持续燃烧小队成员的生命时长作为维持成本。人数越少，消耗越恐怖；只剩2人及以下，领域直接无法开启。
 
3. 殉决瞬爆
 
危急时刻，小队可以选择部分成员短时透支生命，爆发一击。
合力攻击可以击伤T0.5层级目标，击溃残念聚合体，撕碎T0投影分身。
代价：发动透支的成员会损耗寿命、记忆，严重情况下直接死亡。
即便全力爆发，依旧无法对T0本体造成伤害。
 
编制与分工（固定3‑5人，职能划分，不写外貌）
 
1. 契枢：契约锚点，负责维持「残炬同契」稳定，解析敌方权能、领域弱点，统筹小队战术。不能脱离其余队员单独作战。一旦契枢阵亡，同契直接崩解。
2. 破域手：主操作破械套件，专门针对敌方T0.5私域，负责打开领域缺口、解除拘禁，小队攻坚核心。
3. 守御者：承载分摊大部分仪式代价，撑起残炬隔障的基础壁垒，承担伤害。
4. 【可选第4人：侦殉】远距离情报预警，提前探测裂隙畸变、高位存在靠近，提前规避敌方领域的预判拖拽。
5. 【可选第5人：愈契】缓和同契带来的反噬伤害，延缓生命消耗速度；战斗输出能力最弱。
 
标准配置：3人版＝契枢+破域手+守御者；5人满编＝契枢+破域手+守御者+侦殉+愈契。
 
代价与固有短板
 
1. 战力依赖集体联动
拆散小队，个体战力回归普通精英人类水准，不再具备T0.5中位力量。契枢阵亡，整个小队体系直接瘫痪。
2. 力量等价交换
每一次高阶作战都在消耗队员生命、记忆。打越多硬仗，队员衰老越快，记忆不断流失，小队存在天然寿命上限。不存在永续作战的可能。
3. 对抗T0.5三巨头局限
可以干扰三大战鬼的领域、救出被俘人员、小规模击退对手；不具备击杀古德里安、邓尼茨、里希特霍芬的能力，作战目标以救援、阻截、撤退优先。
4. 距离枷锁
残炬同契、残炬隔障都有有效作用距离，队员分散太远，全部高阶能力作废。很容易被敌人分割逐个击破。
5. 面对高位差距
遭遇T0本体只能逃亡，所有手段几乎全部失效；
 
阵营关系
 
1. 与烬火守序【余烬议院】：隶属关系。接受议院下达任务，拥有高度战术自由；拒绝无意义的送死命令，可以驳回不合理指令，但不会背叛人类阵营。
2. 与恶魔以及麾下三大T0.5：死敌。经常交手，主要应对三巨头局部突袭、领域掳走现世目标的事件。小队擅长破域救人，尽量避免正面死战。
3. 与忌夜普通畸变：剿灭主动侵蚀现世的怪物，对中立忌夜存在保持监视，不主动寻衅。
4. 与T0层级：尽量规避接触，只在对方投放投影作乱时出手。
 
层级总结
 
- 规模：3‑5人精英小队，隶属于烬火守序；合力T0.5中位，单人达不到T0.5。
- 核心：残炬同契共享契约，联合领域【残炬隔障】，主打破域救援、危机处置。
- 强项：对抗T0.5强制拉入领域，制造缺口解救被拘禁目标。
- 上限：可重创T0投影分身，无法伤及T0本体；对论外欢愉无解。
- 弱点：惧怕分割打散，力量依靠集体，持续作战会不断损耗队员生命。
